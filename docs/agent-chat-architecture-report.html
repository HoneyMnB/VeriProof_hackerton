향후 아키텍처 고도화 로드맵

상용 플랫폼 수준의 완성도를 달성하기 위한 3단계 점진적 아키텍처 개선 계획입니다.

01
Phase 1: SSE 토큰 스트리밍
Django `StreamingHttpResponse` 또는 ASGI를 도입하여 어시스턴트의 생각과 텍스트를 실시간 청크 단위로 스트리밍. 마지막 청크에서 구조화된 Canvas 메타데이터를 전송하여 사용자 체감 지연(TTFT)을 80% 이상 개선.
02
Phase 2: Multi-turn Function Calling
Gemini 네이티브 Function Declaration 기반 다단계 에이전트 루프 도입. "지갑 조회 → 이전 라이선스 판매 이력 분석 → 적정 가격 계산 → 등록 캔버스 제안"으로 이어지는 자율적 복합 태스크 처리.
03
Phase 3: Direct S3/GCS Presigned Upload
대용량 고해상도 비디오나 마스터 오디오 파일 등록을 위해, 웹서버를 거치지 않고 오브젝트 스토리지로 직접 업로드하는 Presigned URL 체계 구축 및 비동기 Celery 해시 추출 파이프라인 결합.
